# Cage v0.1.8-rc

这是 v0.1.8 的候选版，供愿意提前验证的用户使用。提供 Apple Silicon macOS、Windows x64、Linux x64 和 Android arm64 安装包；当前正式版仍为 v0.1.7。

## 使用与升级

升级前保存工作、停止环境并退出 Cage，再安装对应系统的安装包。继续使用原有账户、收藏、配置、项目和持久磁盘，无需重建环境。工作台提示更新环境工具时，可在“设置 → 环境版本”中更新。

Windows v0.1.7 用户请从本版本附件下载安装程序，退出 Cage 后手动安装。该版本包含自动更新修复；详细步骤见 [Windows 使用指南](https://claude-cage.com/docs/windows/)。

## 主要改进

- **浏览与登录。** macOS 工作台使用 Chrome 原生窗口浏览和登录；Ubuntu 工作台使用稳定版 Chromium，并保留已有浏览器资料。修复 Chromium 语言包迁移失败的问题。
- **Windows 更新与恢复。** 修复更新时应用目录仍被进程占用，以及可信登录下停止环境的鉴权问题；改进更新失败后的恢复与错误提示。
- **Claude 账户恢复。** 已有账户缺少登录凭据时可以重新授权，并在恢复过程中保留其他账户及并发登录数据。Claude Desktop 更新保留登录数据。
- **画面、滚动与声音。** 改进远程工作台的触控板滚动距离和高延迟下的连续滚动；修复采集期间显示活动状态的恢复，并压缩静音音频数据。
- **工作台与连接。** 显示环境时区的当地时间，及时释放已结束或取消的代理连接。调整客户端、剪贴板和手机会话传递的管理信息；这些调整不保证第三方无法识别运行环境。

Claude Code 和 Claude Desktop 继续在实际下载安装时解析对应平台的官方最新版本，保留已经安装的更新版本。下载或验证失败时可以修复网络后重试。

## 验证范围

公开附件应包含三平台安装包、对应源码归档和 `SHA256SUMS`。签名、公证、构建及自动化测试的最终结果以本次发布记录为准。完整客机创建、真实 Claude 账户授权和模型请求、重启后的恢复、各类 Hyper-V 硬件配置、Windows 原生菜单在不同显示缩放下的表现，以及手机配对仍需要实机验收。

Android APK 要求 Android 8.0+，从本版本标签对应源码构建，沿用 v0.1.7 的签名证书，更新序号为 4。已通过签名、非调试属性及 16 KiB 对齐检查，并在 Android 15（API 35）模拟器中验证从 v0.1.7 覆盖安装、启动、主题设置和设备密钥身份保留。公开 APK 已匿名下载并核对 SHA-256；手机实机配对仍需验收。
