# Cage v0.2.0

Cage v0.2.0 正式发布，带来完整的插件平台与插件市场、远程主机与本机 SSH 导入、虚拟机硬盘上限手动增减、工作台视觉与交互全面升级、多账号与独立 Claude Desktop 实例强化、更广泛的代理与出口兼容能力，以及 14 语种本地化全面完善。

## 重要变更与升级提示

- **默认隔离环境调整为纯终端 Debian 13。** 既有环境与个人数据（`~/.claude-cage`）保留不变，升级不会清空账户、会话历史或持久磁盘；如需全新环境说明，请参考 [环境系统说明](https://claude-cage.com/docs/guest-systems/)。需要本机软件与桌面能力时，请使用插件。
- **Windows v0.1.7 及更早版本用户**请从本版本附件下载安装程序，退出 Cage 后手动安装；详细步骤见 [Windows 使用指南](https://claude-cage.com/docs/windows/)。
- **Intel Mac 支持。** 源码构建、打包校验与应用内更新链路已纳入 Intel Mac 正式支持范围；本版本附件提供 Apple Silicon（`arm64`）官方签名公证 DMG、Windows 签名安装包、Linux Debian 软件包及 Android 官方签名 APK。

## 主要改进

- **插件平台、插件市场与默认预装能力。**
  - 环境内的 Claude 可通过插件调用本机工具或运行在环境内的插件；支持插件市场检索、分类筛选、引擎切换、安装/更新/卸载、单工具细粒度启停、插件设置与密钥配置，以及本机调用前审批与记住授权。
  - 新增默认预装可卸载插件、内置 `cage-plugin`（查找与创建插件）及受控 `use-cage` 插件；支持远程主机插件运行、自动增量同步、审批回流与本机插件反向桥接。
  - 支持编号 Claude Desktop MCP 配置同步，以及在终端中通过斜杠显式调用 MCP Prompts。
- **虚拟机资源：手动调整硬盘空间上限（扩容与释放）。**
  - 在「设置 → 资源」中新增「硬盘上限」配置项（与 CPU、内存并列），实时显示本次启动的硬盘上限、环境内用量与宿主机实际磁盘占用。
  - 调大上限后客机启动自动扩展根分区与文件系统；调小上限带安全余量校验与二次确认，通过离线缩容、GPT 分区表迁移、`fstrim` 与宿主镜像空洞回收/重压缩（macOS APFS `F_PUNCHHOLE`、Linux `fallocate`、QEMU `qcow2`）安全释放宿主磁盘空间，并在执行前自动备份、失败自动回滚。
- **工作台视觉与交互升级。**
  - 全面打磨工作台首页、账户、账号管理、设置与代理节点分组的视觉设计语言，简化就绪页卡片，清理侧栏操作按钮冗余内联悬停文字（保留纯图标与悬浮气泡提示）。
  - 工作台侧栏支持鼠标拖拽调整宽度（`216px–520px` 且自适应视口上限，双击恢复默认宽度并持久化保存，支持键盘无障碍调节）。
  - Windows 系统托盘右键菜单外观升级并与应用主题配色自动同步。
- **远程主机与独立 Claude Desktop 实例。**
  - 支持从本机 `~/.ssh/config` 直接导入远程主机，固定 SSH 主机公钥时按公钥类型准确限定协商算法。
  - 支持多账号共享会话历史、记忆、技能、指令与钩子（登录凭据与组织托管内容保持隔离），支持安全删除已绑定 Claude 账号、Desktop 实例重命名/删除与多实例共享剪贴板及宿主文件门户。
  - 补齐独立 Desktop 时区/语言对齐、认证浏览器加固，以及客机浏览器恢复可见时自动强制全屏。
  - 自动生成会话标题时跳过 Claude Code 斜杠命令内部记录；移除共享项目目录的凭据路径误拦截限制。
- **网络、代理与出口兼容增强。**
  - 新增 TLS ClientHello 分片兼容开关，支持从 Surge、FlClash、Clash Party（原 Mihomo Party）与多种分享链接（含 VMess gRPC、Hysteria2 多端口）导入节点并批量测速。
  - 忽略非 HTTP(S) 的 `proxy-server-nameserver` 以避免阻断本机与订阅导入；按订阅来源限定节点域名 DNS；增强代理健康检测与自动恢复；扩充多厂商出口 IP 备用检测服务以提升不同代理环境的兼容性。
  - 支持自建 Headscale 与自托管 tailnet，拒绝误把本机代理端口设为节点。
- **一键换机、终端体验与性能。**
  - 「设置 → 环境与恢复」提供快速换机（原地重置设备标识，已补齐清理覆盖面）与彻底换新机（先验证新环境再处理旧环境，失败自动回滚）。
  - 新增终端回合完成/等待确认的系统通知（默认关闭）；优化资源探测、会话发现、用量统计与窗口隐藏时的后台轮询开销。
- **14 语种本地化与跨平台原生对话框统一。**
  - 修复代理设置与全局工作台 14 语种（含俄语等）文案泄漏与缺失词条，并统一 macOS、Windows、Linux 原生对话框的多语言文案。
- **上游软件默认最新。**
  - Claude Code 与 Claude Desktop 继续在用户下载安装时动态解析对应平台的官方最新版本（发版复核：Claude Code npm `@latest` `2.1.330`、Claude Desktop 官方 APT `stable` 源可用）。

## 验证范围

- **自动化 CI 与签名公证**：macOS（Apple Silicon 正式签名公证、Intel 自动化检查）、Windows（eSigner 代码签名与安装/更新验证）、Linux（Debian 打包与 Debian 12 / Ubuntu 24.04 兼容性验证）均通过 CI 或正式发布构建校验。
- **本地专项验证**：macOS 本地通过前端全量单元测试/lint/构建、Go 测试（含合成 GPT 迁移、raw 镜像缩容/提交/回滚与真实 APFS 空洞回收验证），Windows/Linux 通过交叉 `go vet` 与 GitHub Actions 对应平台构建检查。
- **未实机验证范围**：Windows/Linux 真机运行时与真实虚拟机端到端离线缩容、搭载 NVIDIA 显卡的 Linux 机器、真实 Headscale 服务器、桌面控制插件实机动作，以及 Android 真机配对与完整真机验收。

Android APK 要求 Android 8.0+，从本版本标签对应源码构建并沿用既有签名证书（`versionCode 8`）。
