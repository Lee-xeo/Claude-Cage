# Cage v0.2.0

v0.2.0 正式版发布。这是一次架构与体验的重大升级：隔离环境统一为 Debian 13，正式引入插件平台、插件市场与默认预装可卸载插件，全面翻新工作台界面设计语言，并包含自 v0.1.8 与 v0.2.0-rc 以来的大量网络、代理、SSH、多账号与跨平台稳定性改进。

本版本提供 Apple Silicon macOS、Windows x64、Linux x64 和 Android arm64 安装包；Intel Mac 源码与 CI 检查已同步维护，当前公开安装包暂不包含 Intel Mac 发行物。

## 使用与升级

升级前请保存工作、停止环境并退出 Cage，再安装对应平台的安装包（macOS 与 Windows 也支持在应用内检查更新并自动升级）。账户、收藏、代理、配置、SSH 主机、已添加项目与持久磁盘均会保留；Cage 不会删除或改动旧环境的磁盘。工作台提示更新环境工具时，可在「设置 → 环境版本」中更新。

本版本不再支持创建 macOS、Windows 或 Ubuntu 环境，统一使用 Debian 13。早期创建过其他系统环境的用户，升级后首次启动会新建 Debian 环境：只保存在旧系统磁盘里的文件、工具和登录状态不会进入新环境，需要重新登录 Claude。旧磁盘仍留在原位置（旧 Ubuntu 环境也可一键移至 `state/guests-removed` 归档），确认无需保留后可自行删除以释放空间；详见[环境系统说明](https://claude-cage.com/docs/guest-systems/)。需要本机软件与桌面能力时，请改用插件。

Windows v0.1.7 用户请从本版本附件下载安装程序，退出 Cage 后手动升级一次；详细步骤见 [Windows 使用指南](https://claude-cage.com/docs/windows/)。Android 用户可直接覆盖安装（沿用既有签名证书，`versionCode` 升级至 8），保留已配对连接与主题设置。

## 主要改进

- **插件平台、插件市场与默认预装插件。** 环境内的 Claude 可以通过插件安全调用电脑上的工具，也可运行在隔离环境内。支持从市场安装、更新、卸载、按类别筛选与单独启停，并可细粒度限定工具权限；主机插件设有总开关、每次调用前弹窗确认与授权管理。新增可卸载默认预装插件 **`cage-plugin`**（先查插件市场再协助创建与提交自定义插件草稿，经源码与权限审核后一键安装）与受控 **`use-cage`** 插件，支持卸载后按需恢复安装及远程连接场景下的插件支持。缺少 `uv`、`npx` 或 `python3` 时自动给出安装引导；官网新增插件市场页面（`/plugins/`）。
- **工作台界面全面优化。** 统一视觉设计令牌与高对比次级文字层级，侧栏按工作区 / 插件 / 项目清晰分组（`Tailscale` 归入「插件」分栏，点击 Logo 直达工作台主页），移除主页多余顶栏项目条与启动后的重复提示；全站采用贴边自动隐藏滚动条；重构账户主页用量热力图与安全卡、Claude 账号紧凑卡片、设置分组与主题预览卡片；代理节点支持按国家/地区关键词与国旗自动分组，地区标签栏默认两行折叠并支持展开全部；Windows 端优化系统托盘右键菜单圆角外观、矢量图标与工作台主题/系统深浅色同步。
- **本机 SSH 配置一键导入。** macOS、Linux 与 Windows 用户可在「SSH 主机」侧栏预览本机 `~/.ssh/config`（或 `%USERPROFILE%\.ssh\config`），勾选后批量导入并保留已有记录与已核对指纹。仅使用本机 SSH agent，不读取私钥、不调用 `ssh -G`、不保存私钥路径，跳板机或不支持的指令会明确提示跳过原因。
- **网络与代理增强。** 新增可选的 **TLS ClientHello 分段传输兼容模式**（保留完整后量子加密握手与代理隔离，缓解部分代理链路握手 EOF 或间歇性「出口待确认」）并细化 TLS 握手错误分类；支持自动导入 Clash Verge Rev、Clash Party、FlClash、Surge 等本机代理配置（忽略非 HTTP 的 `proxy-server-nameserver` 避免阻断导入，并拒绝把本机代理端口当作节点）；支持代理健康自动恢复、DoH 备用回切主线路、按路由按需启用 IPv6、自建 Headscale 与自托管 tailnet、分享链接导入与批量测速、可选 `ipinfo.io` 国家级回退。
- **多账号共享与独立 Claude Desktop 优化。** 多账号共享会话历史、记忆、技能、指令和钩子，侧栏可直接切换账号继续未打开的会话，同时严格隔离登录凭据、插件令牌与组织托管内容；完善独立 Claude Desktop 剪贴板跨窗保活、文件传输、默认实例合并提示、终端菜单账号刷新与退出时释放空闲本机后台。
- **一键换机与环境恢复。** 「设置 → 环境与恢复」提供快速换机（原地重置设备标识）与彻底换新机（重建环境），支持逐项选择清理范围、归档至恢复批次以及失败自动回滚；支持缺失存储目录重新定位、中断的 `dpkg` / 首次构建自愈及保留可恢复的下载缓存。
- **终端、浏览器与项目体验。** 自动生成会话标题时跳过 Claude Code 斜杠命令（如 `/clear`、`/model`）内部记录；客机浏览器恢复可见时始终强制全屏，避免露出 Chromium 原生标签栏，关闭浏览器视图时自动收起瞬时错误横幅；移除共享项目目录中过严的凭据路径拦截限制；新增 Claude Code 终端系统通知（默认关闭，不含提示词或回复内容）；改进文件粘贴与剪贴板时序，修复富文本被改写为图片的问题。
- **性能与多语言。** 降低资源探测、会话发现与网络轮询开销，窗口隐藏时暂停实时网速并放缓轮询，优化大量历史下的用量统计速度；全面补齐俄语在内的 14 种界面语言翻译，修复 Windows / macOS / Linux 跨平台兼容性与安装构建细节。

Claude Code（默认解析 npm 官方 `@anthropic-ai/claude-code@latest`）与 Claude Desktop（默认接入官方 `https://downloads.claude.ai/claude-desktop/apt/stable`）继续在实际下载与更新时动态获取对应平台的官方最新版本，并保留已安装的更新版本。

## 验证范围

- **自动化与签名验证**：本版本已通过 macOS（Apple Silicon 与 Intel）、Windows 和 Linux（Debian 与 Ubuntu 软件包兼容性）完整 CI 检查。Apple Silicon macOS App 与 DMG 完成 Developer ID 签名、Apple 公证、装订及 Gatekeeper 验证；Windows 安装器完成可信 Authenticode 签名与云端安装验收；Linux `.deb` 完成 Debian 12 / Ubuntu 24.04 兼容性验证；Android APK 沿用既有发布签名证书（`versionCode` 8）并完成签名与 16 KiB 对齐校验。全部安装包与对应开源组件源码均附带统一 `SHA256SUMS` 清单，并由官网工作流完成匿名公开下载校验。
- **未在真机全量验收的范围**：托管 CI、容器及本机自动化测试不代表所有硬件环境均已实机验收，包括真实 Windows Hyper-V、Linux KVM / NVIDIA 驱动、Intel Mac 客机、真实 Headscale 服务器、Android 物理机覆盖升级与扫码配对，以及真实 Claude 账户授权与模型请求流程。

已知限制：

- 重建环境被中断时，旧环境会保留为归档，但暂不支持一键恢复。
- 快速换机中途失败时，环境与主机的身份信息可能不一致，相关数据保留在恢复批次中。
- 不通过官方卸载入口、而是手动删除插件或 MCP 时，需要重复操作一次才能同步到其他账号。
- 本版本暂不支持导入 `socks://` 分享链接。
