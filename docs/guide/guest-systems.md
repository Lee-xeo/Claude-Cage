## 一个环境，三个平台

Cage 在电脑上运行一台轻量化的 Debian 13 虚拟机，官方 Claude Code 和 Claude Desktop 都在这个环境里运行。macOS、Windows 和 Linux 上的 Cage 统一使用同一个环境，不再维护复杂的多系统客机；需要本机桌面、文档或软件能力时，直接通过[插件与插件市场](plugins.md)按 MCP 受控调用即可。终端、浏览器、编辑器和 Claude Desktop 的操作方式三端一致，无需选择系统。

| 你的电脑 | 环境架构 | 需要的虚拟化能力 |
| --- | --- | --- |
| Apple Silicon Mac，macOS 14+ | Debian 13 ARM64 | 系统自带，无需额外设置 |
| Intel Mac，macOS 14+ | Debian 13 x86_64 | 系统硬件虚拟化可用（终端运行 `sysctl kern.hv_support` 显示 1）；使用随附的 QEMU 与 Hypervisor.framework |
| Windows 10 22H2 / 11 x64 | Debian 13 x86_64 | BIOS/UEFI 虚拟化与“Windows 虚拟机监控程序平台” |
| Debian 12、Ubuntu 22.04 / 24.04 x86_64 | Debian 13 x86_64 | KVM，以及当前用户对 `/dev/kvm` 的读写权限 |

Windows ARM64 和 Linux ARM64 暂不支持。Windows 家庭版同样可用：在“启用或关闭 Windows 功能”中勾选“Windows 虚拟机监控程序平台”并重启即可；“虚拟机平台”“适用于 Linux 的 Windows 子系统”和 Hyper-V 都不是 Cage 的要求。各平台的安装步骤见[安装与首次启动](installation.md)。

## 环境里有什么

- **终端与 Claude Code。** 终端使用 Linux 工具链，随环境安装 Git、Python、Node.js、编译工具、GitHub CLI 和 mise。
- **浏览器。** Chromium 运行在环境内，用于登录、授权和预览开发服务，见[浏览器与网站数据](browser.md)。
- **编辑器。** code-server 在工作台标签页中打开项目文件。
- **Claude Desktop。** 需要时在工作台安装官方 Linux 版，见[Claude Desktop](desktop.md)。需要额外虚拟机的 Cowork 暂不支持。
- **插件与插件市场。** 通过侧栏「插件」打开开放插件市场（`cage-plugins`），按需安装主机或环境内插件（**插件 = MCP + 扩展**），让环境里的 Claude 安全、受控地调用本机能力（如屏幕键鼠、Office 文档、Blender、命令执行等），或为工作台增加自定义沙箱页面。主机插件默认受权限声明与确认弹窗保护，见[插件与插件市场](plugins.md)与[插件开发规范](https://github.com/Lee-xeo/Claude-Cage/blob/main/docs/plugins.md)。

环境只有一个。所有项目共用其中的系统、工具、账户和文件系统，切换项目不会创建另一台虚拟机。

## 首次创建环境

1. 按[安装与首次启动](installation.md)安装 Cage，创建或解锁 Cage 账户。
2. 在初始化界面的“系统与存储”中确认存储位置，再配置自己的代理。
3. 点击“开始安装”。Cage 下载并校验 Debian 13 基础镜像，创建虚拟磁盘，再安装浏览器、编辑器和开发工具。
4. 网络与隔离检查通过后点击“进入工作台”，打开项目、新建终端，在 Cage 内完成 Claude 授权。

安装卡片显示当前阶段。下载镜像时可看到已下载大小、总量、百分比和采样速度，校验单独显示进度。中断后点击“继续安装”，复用原安装记录和已保存的下载。以后启动沿用同一环境，工具、文件和登录状态都保留。

Cage 不会把主机的系统账户、Claude 登录、浏览器资料或 SSH 密钥导入环境。

## 下载量与磁盘空间

Debian 13 基础镜像约 320–325 MiB，按处理器架构下载一份。虚拟磁盘的初始容量上限为 24 GiB，按实际写入增长；浏览器、编辑器、开发工具和按需安装的 Claude Desktop 另占空间。创建前请为镜像、虚拟磁盘、项目产物和更新备份留足空间。

环境可以放在独立数据盘。应用安装目录、Cage 配置目录和环境存储分别管理，共享项目仍在你选择的原目录。选盘和换盘步骤见[环境存储](maintenance.md#迁移环境到另一块磁盘)。

## 打开项目

选择项目后，终端、Claude Code 和编辑器都从这个目录开始工作。共享目录中的修改和删除直接作用于主机原文件，重要项目应使用版本控制或备份。项目共享只限明确授权的目录，下载使用独立的暂存目录，项目内的 Git 元数据可读写。操作方法见[项目、终端与文件](workbench.md)。

为减少与主机的往返，环境默认缓存项目文件的名称与属性，主机上的改动最多 20 秒后可见；需要立即看到时使用“刷新项目文件”，说明见[项目、终端与文件](workbench.md)。

## 创建时的名称与设备配置

首次设置的“系统与存储”中可以填写或随机生成主机名，还可以设置环境内的账户名、主目录、显示尺寸和控制扩展名称。建议使用自然、易记、与你以往环境不同的名称。音频输出名称从内置的产品型号库中自动选择，浏览器保持实际版本的 UA 信息。

浏览器图形后端可选自动、Vulkan、OpenGL 或软件渲染；Linux 主机还可尝试 VirGL 加速。实际效果取决于环境中的设备与驱动。浏览器也可手动关闭 WebGL 或阻止 Canvas 图像读取，可能影响部分网站。

启动后可在安全检查面板检测浏览器和 Claude Desktop。检测会列出实际证据、软件回退及未观测项。这些设置随环境保存，开始安装后不能再改，详见[环境创建配置](https://github.com/Lee-xeo/Claude-Cage/blob/main/docs/guest-profile.md)。

## 更新、重装与数据保留

更新 Cage、重装应用或重新启动都不会更换环境，也不会清空虚拟磁盘。账户、收藏、代理和设置保存在主机的 `~/.claude-cage`；环境里的工具、文件和登录状态保存在持久虚拟磁盘中。备份与卸载步骤见[备份、重装与卸载](maintenance.md#备份重装与卸载)。

环境存储所在磁盘未连接或迁移尚未完成时，工作台会提示“环境存储需要恢复”。连接原磁盘后，在设置的项目与环境页面点击“重试恢复”。恢复完成前不要另建环境或删除原虚拟磁盘。

旧版默认项目若位于 Cage 配置目录中，升级后保留该目录中的文件。请按设置页显示的旧目录找到项目，将其移至配置目录之外的专用项目文件夹后，再从工作台打开。

## 早期版本创建的其他系统

早期版本曾支持创建 macOS、Windows 11 或 Ubuntu 环境。随着 Cage 确立「轻量化本地隔离环境 + 开放插件市场（MCP + 扩展）」的路线，当前版本不再维护复杂的多系统客机，统一使用 Debian 13 环境，需要本机软件与桌面能力时直接通过[插件与插件市场](plugins.md)安全桥接：

- Cage 账户、代理、收藏、设置和已添加的项目继续使用，共享项目的文件一直保存在主机上，不受影响。
- 旧系统的虚拟磁盘、安装介质和配置文件留在原配置目录与环境存储位置，Cage 不读取、不修改，也不删除它们。工作台首页会提示这些数据仍在磁盘上。
- 首次启动时创建新的 Debian 环境。只保存在旧系统磁盘里的文件、工具和登录状态不会进入新环境，需要在新环境中重新登录 Claude。

旧 Ubuntu 环境与 Debian 环境共用同一个环境存储位置，Cage 不会自动挪动它，因此启动时会提示 Ubuntu 客机已不再支持。在工作台首页的提示中点击“保留旧 Ubuntu 环境并新建 Debian”并确认后，Cage 先停止旧环境，把它的虚拟磁盘、安装镜像和系统选择记录按原有目录结构移到 Cage 配置目录下的 `state/guests-removed/ubuntu-<版本>-<时间>` 文件夹（环境存储放在其他磁盘时，该文件夹也在那块磁盘上；只移动，不复制、不删除，并附 `manifest.json` 列出移动的文件），再下载并创建 Debian 环境。环境内的账户名、主机名等创建配置沿用原设置。任一文件移动失败时，已移动的文件会放回原处，旧环境保持原样。

确认旧系统里没有需要保留的文件后，可以自行删除这些数据（包括 `state/guests-removed` 中的文件夹）以释放空间；删除前请先备份。

## 云端和手机如何配合

云端模式运行在自己的 Linux 服务器上，使用容器，无需服务器提供 KVM。通过侧栏 SSH 进入远端后，项目、程序和网络出口都属于所选服务器，本机虚拟机可以保持关闭。见[云端部署与 SSH](cloud.md)。

手机用于连接电脑上的 Cage，接续 Claude Code 会话、处理工具审批和操作远程窗口，任务仍在电脑上运行。手机不运行 Cage 环境；连接方式见[手机连接与远程会话](mobile.md)。
