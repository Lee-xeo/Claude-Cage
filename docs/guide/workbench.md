## 打开项目与编辑文件

终端和工具运行在 Cage 的 Debian 环境里，使用 Linux 工具链；浏览器、编辑器和 Claude Desktop 都从同一个工作台进入。环境的要求与内容见[Debian 环境](guest-systems.md)。

点击左侧“项目”旁的加号，选择已有项目，或点“添加本机项目…”创建项目。填写项目名称，连续添加需要一起使用的文件夹，再点击“创建项目”。例如“课程系统”可同时绑定前端与后端目录。项目名称和绑定关系会保存，下次启动继续可用。没有项目时可以使用浏览器与 Claude Desktop；终端和文件编辑器需先添加项目。

第一个文件夹是默认工作目录。新建终端与 Claude 会话从默认文件夹启动，Claude 同时获得其余绑定文件夹的读写权限。不同文件夹的 Git 仓库仍分别管理，修改和删除会直接影响本机原文件，请使用版本控制或备份。项目内的 `.git` 可读写，可直接在 Cage 中暂存、提交和切换分支。

在项目选择窗口选中项目，点击“编辑名称与文件夹…”可重命名、添加或解绑文件夹。默认文件夹用于关联已有会话历史，需保留。修改绑定后，新建或重新打开 Claude 会话生效；解绑前请保存文件，关闭整个项目的终端、运行中会话和编辑器。文件夹解绑只解除共享，原文件与历史保留。

环境默认缓存项目文件的名称与属性，减少每次读取都要与本机往返的开销。代价是你在本机上直接修改、删除或追加的文件，环境最多 20 秒后才看到；环境内所做的改动始终立即可见。刚在本机改过文件、需要环境马上看到时，点击“项目”旁加号左边的“刷新项目文件”。正被某个程序打开着的文件仍要等缓存到期。经常在本机和环境里同时编辑同一批文件时，可以在“设置 → 通用”关闭“项目文件缓存”，下次启动环境后每次读取都直接访问本机。

项目旁的打开图标（↗）在 code-server 中编辑默认文件夹。多文件夹项目展开后，每个文件夹还有单独的编辑器入口。终端图标（>_）用于选择终端类型，项目内各文件夹已有的会话集中显示在项目下。手机上的项目名称、会话分组和新建会话使用相同绑定关系。

在项目选择窗口选中项目，点击“从 Cage 移除此项目”并确认，可解除全部绑定文件夹的共享并从列表移除。请先保存文件并关闭该项目的终端、运行中会话和编辑器。原文件与会话历史保留，重新添加相同默认目录后可继续使用历史。移除当前项目后选中剩余项目；移除最后一个项目后，项目列表为空。环境停止时也可移除项目。

已有的单文件夹项目可直接编辑并添加更多文件夹。临时共享给云端的本机项目仍通过“共享本机项目…”单独授权，断开连接后结束共享。

所有项目共用一个环境、工具和账户。切换项目不会改变已有终端的目录，也不会关闭网页或撤销之前的共享。云端的目录与权限见[云端部署与 SSH](cloud.md)。

共享文件在环境内显示为当前用户所有，Git 可正常读取已打开项目的状态与历史。文件内容仍属于原来的主机目录，Git 元数据与项目一起共享，环境中的 Git 操作会直接更新主机仓库。授权目录内的隐藏文件、工具配置、Git 配置和钩子均按普通项目文件共享。Cage 不按文件名额外隐藏文件或禁止写入；云端共享的整目录只读授权仍然生效。

## Git 提交与 GitHub 登录

Git 可以在已共享的可写项目中暂存、提交和切换分支。首次提交前，在 Cage 的普通终端中检查提交者信息；没有配置时，填写自己希望出现在提交记录中的姓名和邮箱。GitHub 的隐私邮箱也可使用。

```sh
git config --global --get user.name
git config --global --get user.email
git config --global user.name "你的提交者姓名"
git config --global user.email "你的提交者邮箱"
```

全局设置作用于当前环境内的所有项目。单个项目需要不同身份时，在项目目录中用 `--local` 代替 `--global`。仓库已有的本地设置优先；若提交要求 GPG 或 SSH 签名，需要在环境内另行配置签名工具与密钥。

推送私有仓库、管理 PR 或关闭 Issue 还需要 GitHub 授权。GitHub CLI（`gh`）随环境工具安装；旧环境提示找不到命令时，先到“设置 → 环境版本”更新环境工具，再新建普通终端。macOS、Windows 和 Linux 使用相同的登录命令：

```sh
gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git --hostname github.com
gh auth status --hostname github.com
```

按终端提示打开 GitHub 授权页，输入一次性代码并由本人确认授权；浏览器没有自动打开时，也可手动访问终端显示的地址。`gh auth setup-git` 让 HTTPS Git 操作使用这次登录。具体行为见 [GitHub 登录说明](https://cli.github.com/manual/gh_auth_login)和 [Git 凭据配置说明](https://cli.github.com/manual/gh_auth_setup-git)。

登录保存在当前环境中，重启和更新继续保留；本机 Chrome 的登录、SSH 私钥与 Git 凭据不会自动导入。`gh` 优先使用系统凭据存储，不可用时会保存到环境内的配置文件，可用 `gh auth status` 查看存储位置。浏览器登录和命令行授权分别管理。

登录完成后，检查项目的远端地址。HTTPS 授权不会替 SSH 地址完成认证；若 `origin` 仍使用 `git@github.com:…`，可在确认仓库地址后改为 HTTPS：

```sh
git remote -v
git remote set-url origin https://github.com/仓库所有者/仓库名.git
git push
```

登录账户仍需拥有目标仓库的写入权限；组织 SSO、分支保护和工作流权限继续由 GitHub 管理。

## 新建 Claude 终端

1. 点击项目旁的终端图标，选“新建 Claude 终端”。Cage 会在默认文件夹启动 `claude`，并让它访问项目内其余绑定文件夹。
2. 首次使用按官方提示登录，授权页面在 Cage 浏览器中完成。主机已有的 Claude 登录不会自动导入。
3. 有多个订阅时，先按[多账号与额度](accounts.md)登记；新建的 Claude 终端标签会显示分配的账号。

Claude Code 标签使用 Agent 图标，带编号时表示该会话绑定的账号编号；普通终端继续使用终端图标。账号分配与跨账号接续由[账号设置](accounts.md#在同一会话中换账号)管理，图标本身不切换身份。

Cage 的共享 Claude 会话会先显示“正在准备 Claude 会话…”，在后台确认自身通道的启动提示，再显示会话画面。需要查看登录或排错信息时，点击“显示启动过程”；准备超过 8 秒会自动显示终端，避免卡住的提示被隐藏。普通终端仍直接显示输出。

也可创建普通终端，自行运行 shell 命令。在“设置 → 通用 → Claude 终端启动命令”添加参数，例如 `claude --continue`。只对以后新建的 Claude 终端生效，退出 Claude 后 shell 仍可使用。

移动端的结构化会话与普通终端分别管理，详见[手机会话范围](mobile.md#创建会话与处理工具审批)。

历史列表提示读取失败时，已经显示的历史继续保留，旧的活跃标记会清除。点击重试按钮核对最新状态；正在读取时按钮禁用，原因仍可复制。持续失败请按[会话读取故障](troubleshooting.md#claude-登录与账号异常)检查环境连接与诊断信息。

### 让 Claude 委派给本机 Codex（本地预览）

在工作台新建 Claude 终端后，可以说「请 Codex 在当前项目里检查这个测试」，收到回答后再追问。第一次派活时，Cage 为这个终端创建专用 Codex 会话。每个终端一次处理一条委派，Claude 通过 MCP 取回对应的最终回答。关闭终端或锁定 Cage 会结束这段 Codex 会话。解锁后新开 Claude 终端可以再次派活。

预览需要宿主机上的 Codex 已登录，并支持 App Server 的命名权限配置和外部工具消息。启用时，在宿主机的 Cage 配置目录（默认 `~/.claude-cage`）创建空文件 `codex-window.enabled`，使用随此构建提供的环境组件并新开 Claude 终端即可。停用时移除该文件并关闭相关终端。无需打开 Codex 桌面窗口或选择聊天。

Codex 可以在授权项目内读取和修改文件。专用会话关闭了命令联网和个人 MCP 工具；需要额外授权的操作可能失败。Claude 可以看到 Codex 写入最终回答的内容，用户在其他 Codex 聊天中的消息不会被送入通信窗口。

Mac 主机上的专用 Codex 会话可以使用已安装的 Go、Node/npm 和 Xcode 工具链。构建脚本可用 `mktemp -d` 或 `$TMPDIR` 创建临时产物。需要保留的结果请放进项目目录；会话结束时会清理专用临时目录和编译缓存。

Go 项目可以使用离线模块包。在 Mac 上运行 `uv run --no-project python scripts/prepare-codex-go-proxy.py "/项目绝对路径"`，即可从本机已有的 Go 缓存复制该项目已提交的 `go.sum` 对应的依赖。使用本地替换模块时，可重复传入 `--sum` 指定各个校验文件。npm 构建可直接使用项目已安装的 `node_modules`。

环境里的 **Claude Desktop → Code** 也支持这个窗口。在本地预览中，宿主机把允许使用的 Desktop 账号与已共享项目记录在配置目录的 `codex-desktop-projects.json` 中。Cage 只为匹配的本地 Code 项目登记 `codex` 连接器，并按每段对话单独分配 Codex 会话。首次登记后，新开同项目的 Code 对话即可加载；已有对话可能需要重开。工作台侧栏切换项目不会改变这段对话的委派目标。

## 管理标签与分屏

鼠标移入终端行或用键盘聚焦后，可置顶、重命名或删除。网页标签可右键或按 Shift+F10 打开菜单；拖动可在同一列表排序，Esc 取消拖动，刷新保留顺序。页面过多时用向下箭头搜索已打开的网页。

工作台支持网页与终端组合使用；普通网页也支持双页分屏。无痕网页可与终端分屏，双网页分屏仅支持普通标签。浏览器右上角 × 返回之前的工作区，已打开的网页和登录状态保留。

macOS 用 `⌘1–9` 切换当前网页或当前目录的终端；Windows/Linux 工作台对应使用 Ctrl。终端中的 Ctrl+C 始终用于中断命令。

## 上传、下载与附件

网页选择上传文件时，会显示“上传本机文件”，点击“选择本机文件”调用系统窗口。一次最多 100 个文件，单文件最多 2 GB；网站还可能有更小限制。只传递选中的文件，不会因此共享整个文件夹。取消、刷新或关闭原网页后需重新选择。

可以把图片、音视频和文档拖到支持附件的目标，或在文件管理器复制后到 Cage 粘贴。终端会把附件存入环境目录并插入带引号的路径，供 Claude Code 读取，不自动执行。截图粘贴最多 20 MB、4000 万像素；文件传输不使用外部存储中转。

浏览器上传、桌面/终端附件、截图粘贴和主机文件剪贴板（包括文件夹）都遵循“支持格式自动清理 → 无法安全清理时由用户选择是否原样传递”。清理在主机侧完成，不使用外部存储或在线清理服务。

默认不原样传递无法安全清理的媒体。确需使用时，可在**设置 → 通用**中明确勾选并保存**“允许未支持格式原样传递”**。开启后，这类文件可以保留原始字节传递，GPS、时区偏移、地区代码等元数据可能保留；受支持的文件仍优先自动清理。该选择保存在当前 Cage 配置中，同时适用于上传和文件剪贴板；关闭后对新的传递生效，已导入的副本不会被追溯撤回。

| 格式 | 自动清理范围 | 保持可用性的处理 |
| --- | --- | --- |
| JPEG、PNG、GIF、WebP | 已支持的 EXIF/XMP/IPTC、注释和附加文本元数据 | 保留像素、颜色及 GIF 帧/循环；JPEG 重建安全的方向字段 |
| OOXML、ODF | 文档属性、容器注释/原始时间及受支持内嵌媒体 | 保留正文、表格、样式；ODF 的语言、区域和时区设置作为功能设置保留 |
| PDF | 信息字典中的已识别定位、国家/地区和带时区偏移的日期属性，XMP 中相应可选字段 | 使用本地 PDF 对象解析器，保留正文流、字体、编码和文档语言；加密或带数字签名的 PDF 不重写，转由用户决定是否原样传递 |
| TIFF | 经典 TIFF 的 GPS IFD、EXIF 时区偏移及已识别 XMP 地区字段 | 保留压缩图像、页链、方向、ICC 和文件偏移；BigTIFF、GeoTIFF 或重叠/未知布局转由用户选择 |
| HEIC、AVIF | 常见 ISO BMFF 布局中的 Exif/XMP 元数据项 | 保留编码图像、透明度、方向/颜色属性、项目引用及偏移；分散或未知的元数据布局转由用户选择 |
| MP4、MOV、M4A | 已识别的可选定位盒、mdta/ilst 地区及带偏移日期字段、XMP | 不重编码或移动媒体采样；保留时间轴、字幕/音轨语言及索引。未知遥测轨、保护或压缩的元数据结构转由用户选择 |
| MP3 | 常见 ID3v2.3/v2.4 TXXX/PRIV 中明确的地区键及带偏移日期帧 | 保留音频字节、标题和 TLAN 语言帧；不支持的标签变体转由用户选择 |
| FLAC | Vorbis comments 中明确的地区键和带偏移日期，受支持封面图片的元数据 | 保留 STREAMINFO、采样、语言标签、寻址表及曲目提示；未知应用块转由用户选择 |
| PCM/IEEE 浮点 WAV | LIST/INFO、XMP 和填充块中的可选附加元数据 | 保留采样、fact 计数及 cue/loop 标记；BWF/iXML 和未知变体可能承担同步/轨道功能，转由用户选择 |

清理只修改已确认可独立移除的元数据。文档语言、字幕/音轨语言、字符编码、字体、颜色和方向等会影响阅读、播放或显示的字段保留；不对正文、文件名、代码/配置或可见图像内容做地区信息扫描。XMP 等可选描述字段中的明确地区代码会清理，但不会一律删除所有 `zh-CN` 字符串。

未支持的照片、音频和视频格式（如相机 RAW、PSD、BigTIFF、MKV/WebM、AVI、Ogg/Opus、AIFF、WMA），以及受支持格式中结构异常或超过解析预算的文件，会提示上述原样传递选项，不会自动回退。压缩包、旧版 Office 文档、SVG、BMP、ICO、代码和文本等其他文件按原样传递，不做解析。Office 限制单个解压条目 64 MB、总解压内容 256 MB 和 4096 个条目；PDF 解析上限为 256 MB，其他复杂结构也有深度和元数据大小限制。一般文件仍受单文件 2 GB 上限约束。

共享项目目录不做元数据清理，环境直接读写主机上的原文件，以保证构建、版本控制和文件大小与主机一致；放进共享目录的照片、音视频和文档会保留原有元数据。需要清理时，请通过上传、附件或文件剪贴板传入。这里只覆盖工作台上述入口和已识别的元数据结构，共享目录、环境内已有文件、其他访问通道、未识别字段、压缩包内文件和原样传递文件中的元数据仍可能保留。

下载在 Cage 环境内完成。本机模式的完整文件先保留在下载暂存目录，同名自动换名；工作台观察到完成后弹出“另存为”。取消仍保留默认位置的文件。在左侧“下载”或浏览器下载按钮可查看进度、打开、显示文件位置或另存。

云端文件和已经另存到本机的副本分开记录。要在其他应用打开远端文件，先明确保存到本机。

## 输入法与剪贴板

先点击目标输入位置，再复制或粘贴。macOS 终端用 `⌘C/V`，Windows/Linux 终端用 `Ctrl+Shift+C/V`。Cage 桌面应用中的 Claude 终端还支持 `Ctrl+V` 粘贴本机剪贴板里的截图或文字。图片会保存到环境并插入可供 Claude Code 读取的路径；传递完成前按 Enter 会等待，传递失败则取消这次待发送操作。普通网页、编辑器和本机输入框按所选键盘习惯操作；“设置 → 通用”可调整。

Claude Code 自己管理的选区和 `/copy` 发出的文字复制会写入本机剪贴板，并参与现有共享剪贴板同步。终端重连时只恢复历史画面，不重复执行旧的复制。终端程序接管鼠标时，也可在 Mac 按住 Option 拖选，Windows/Linux 按住 Shift 拖选，再复制。Ctrl+C 保持终端中断行为。普通浏览器因权限限制无法使用剪贴板时，可用“文本传递”面板传纯文本。

环境运行期间，Cage 桌面应用让本机、Cage 浏览器和 Claude Desktop 双向共享文字、图片、文件和文件夹的剪贴板。点击应用内的复制按钮后可直接在另一端粘贴；切换画面与窗口失焦继续共享。拖选文字仅改变选区，复制后才更新共享内容。范围、大小限制与文件保留规则见 [Claude Desktop：复制与粘贴](desktop.md#复制与粘贴)。

普通网页工作台中的复制按钮支持把纯文本同步到本机，保持网页和窗口在前台，等待“已复制到本机”。切换标签或输入位置可能取消尚未完成的传递，重新复制即可。

## 关闭、锁定与退出

| 操作 | 对任务的影响 |
| --- | --- |
| 关闭或隐藏窗口 | 环境、终端、网页和下载继续运行。不可见时暂停画面显示连接，返回后重连。 |
| 锁定 Cage | 隐藏工作台并要求验证，已运行的任务继续。手机的受保护操作暂停。 |
| 退出应用时选择保留环境 | 后台任务继续，下次打开重新连接。 |
| 停止环境或退出账户 | 结束运行中的终端，项目、磁盘和登录资料保留。 |
| 刷新工作台 | 可重连后台仍存活的终端。 |
| 重启控制服务或环境 | 旧终端进程不能恢复，需要新建。 |

停止前保存编辑器内容。磁盘里保存的文件与 Claude 历史，不等于能恢复已结束的进程和终端临时输出。
